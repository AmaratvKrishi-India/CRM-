Run the generator after dependency changes:

```powershell
node scripts/generate-third-party-licenses.mjs
```

Before a release, also inspect the built `dist/` and Android dependency outputs because lockfile presence is broader than shipped-code presence. Preserve third-party NOTICE/license files when the selected licenses require them.
