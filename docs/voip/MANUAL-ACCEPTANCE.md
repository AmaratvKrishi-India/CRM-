# One-page acceptance checklist

**Owner-operated only, after security remediation, legitimate TLS trust, commercial carrier permission and reviewed packaging. Current build is mock-only; do not try to enable live calling with configuration.** Consent is required from the owner-controlled test number; never use a customer for initial acceptance. Redact every number, OTP, credential and account-specific response from evidence.

- [ ] Security reviewer clears pinned source fixes, loopback SIP, authenticated/per-user IPC, bounded frames and trustworthy carrier TLS peer validation; license/distribution review complete. Signed or checksum-matched Windows assets correspond to reviewed sources. No broad firewall/Defender/UAC workaround.
- [ ] Owner confirms Jio authorizes commercial CRM use or selects a compliant business alternative. Own JioFiber LAN/Wi-Fi and authorized voice line; no remote/paid infrastructure implicitly provisioned.
- [ ] Windows 11 and actual supported Chrome/Edge version recorded. Test hosted HTTPS handoff, CSP and local-network permission or reviewed opaque protocol intent with **explicit native confirmation**. Wrong origin, unpaired tab, wrong user/device, expired intent, feature OFF and logout produce no call.
- [ ] Bluetooth **microphone input** meter and **headset output** tested independently in Windows Sound. Verify two-way audible RTP on one owner-controlled consented number, ringing, caller ID, answer, end and hangup. Registration/confirmed event alone is insufficient.
- [ ] Exercise no/one-way/delayed audio, null audio device, headset switch, PC sleep, network loss, child crash, reconnect, hung call, port collision, denial, duplicate clicks and repeated nonce. No automatic retry or unsolicited redial; one active call and durable daily policy accepted before live rollout.
- [ ] CRM starts from permitted current lead; DNC and inaccessible leads denied. Outcome/notes/history and tenant/role separation verified. No fake duration, answeredAt or VERIFIED claim. Simulated demo records retain MOCK label. Incoming/answer remains disabled until authenticated matching is separately accepted.
- [ ] Refresh/close/logout/disabled provider cannot produce future calls. Verify revocation in actual live tools, not just mock lease. No carrier secret reaches browser/cloud/logs; no recordings or transcripts.
- [ ] Accessible automated checks and exact head CI pass; Preview synthetic backend is approved and Production is unchanged. Protected Production browser and designated synthetic identity acceptance are separately evidenced, with zero unauthorized writes.
- [ ] Separate Staging and Production encrypted retained backups, download/decrypt integrity, PG17-compatible restore/rollback rehearsal, supported migration metadata reconciliation and provider patch review meet approved recovery gates.
- [ ] Owner explicitly authorizes merge/release after all hard gates. If any gate fails, leave PR open/changes requested and record redacted failure. No default Production feature enablement.
