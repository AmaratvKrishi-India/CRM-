# Rollback

No live telephony, hosted migration, Vercel Production change, firewall rule, Windows service or registry protocol is installed by this task.

1. In CRM Settings choose **Disable and unpair**. If a mock attempt is open, end it, save an explicitly simulated outcome or **Skip / do not record**. Stop the exact companion terminal with Ctrl+C. A network failure may delay lease expiry up to thirty seconds; there is no carrier execution path.
2. Remove local mock environment flags; restart the development server. Refreshing clears the tab's paired token. Delete only the extracted companion directory after confirming that process stopped. No machine-wide kill, service/firewall/registry deletion or credential sync helper.
3. Before merge, remove/revise this PR's feature commits through normal reviewed commits on `chore/post-release-maintenance` if desired; do not reset or force-push. After any separately approved future release, revert the recorded feature commits in a new reviewed rollback PR (`git revert <feature-commit>`), run normal checks and obtain deployment approval. Never push directly to main or invoke Production rollback under this task.
4. Keep synthetic mock history for audit; no automated customer-row deletion or hosted DB rollback. No new schema migration needs reversal. If a later live migration exists, its separately approved backup/restore procedure governs it; do not restore a source project from an unverified archive.
5. Native Android calling remains the original dialer path. Explicitly disable the mock selection before manual fallback. Hardware/carrier failures require stopping the live tools through their separately reviewed shutdown procedure before any future rollout; no supplied upstream installer is approved here.
