# Reference material

This directory contains large or supporting material that is useful to the project but is not application source or living operational guidance.

- [`public-apis/`](public-apis/) contains the source catalog, generated Word document, and the script that rebuilds the document.
- [`assets/`](assets/) contains preserved design/reference assets that are not part of the app's runtime `public/` bundle.
- [`generated/`](generated/) contains the previously tracked build/report bundle, kept together so its relative asset links remain valid.
